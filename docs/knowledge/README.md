# Development Knowledge System

This directory is versioned project memory for future contributors.

## Before authorized work
Read CLAUDE.md, product vision, decisions, development plan, visual asset spec and relevant knowledge registers/reports. Verify live code because old reports may be stale.

## After substantial work
Create a dated report in reports/ using WORK_REPORT_TEMPLATE.md. Record actual changes, decisions, tests, CI evidence, failures, fixes and owner punch-list outcomes. Update patterns, lessons, issues and test history only with verified evidence. Never include secrets or private recipe content.

This is external documentation, not automatic model training; it does not authorize implementation, merging or release.
